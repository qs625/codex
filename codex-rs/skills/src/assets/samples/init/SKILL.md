# Init Repository Instructions

Use this skill when the user asks to initialize repository guidance, create an `AGENTS.md`, or run `/init`.

Create a file named `AGENTS.md` that serves as a contributor guide for this repository. Keep the document concise, specific to the codebase, and written for future coding agents.

Recommended structure:

- `# Repository Guidelines`
- Project structure and module organization.
- Build, test, and development commands.
- Coding style and naming conventions.
- Testing guidelines.
- Commit and pull request expectations.
- Security or configuration notes when relevant.

Keep the content around 200-400 words unless the repository clearly needs more detail. Prefer concrete examples such as commands, directories, and naming patterns. If an `AGENTS.md` already exists, update it in place rather than replacing useful project-specific guidance.
